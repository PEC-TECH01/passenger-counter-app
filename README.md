# Passenger Counter App

A simple and interactive **Passenger Counter App** built with HTML, CSS, and JavaScript. The application allows users to keep track of the number of passengers entering a location and save previous passenger counts.


## 🚀 Features

* Increment the passenger count with a button click
* Save previous passenger entries
* Display saved entries on the page
* Simple and responsive user interface
* Interactive functionality powered by JavaScript
* Clean and easy-to-use design


## 🛠️ Technologies Used

* **HTML5** – Structures the application
* **CSS3** – Provides styling and layout
* **JavaScript** – Handles the application's logic and user interactions

  

## 💡 How It Works

1. Click the **INCREMENT** button to increase the passenger count.
2. Click the **SAVE** button to record the current number of passengers.
3. Saved entries are displayed on the page so previous counts can be viewed.

## 🎯 Learning Objectives

This project was created to practice fundamental JavaScript concepts, including:

* Variables
* Functions
* DOM manipulation
* Event handling
* Updating HTML elements with JavaScript
* Working with strings and numbers
* Connecting JavaScript to an HTML document

## 🖥️ Running the Project

You can run the project locally by:

1. Downloading or cloning this repository.
2. Opening the project folder.
3. Opening `index.html` in your web browser.

No additional dependencies or installation are required.
